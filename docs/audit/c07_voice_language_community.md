# C07 Audit — Voice, Local Language, Education, Community, Nearby Services, Machinery, Labour (Domains 40–46)

Static code + existing-test-suite audit of the Smart Farmer repo (`C:\FARMER_APP\smart-farmer-offline-sync-verified\smart-farmer`) against the domain 40–46 checklist. Methodology: direct file reads/greps (all cited by path, and line numbers where meaningful), plus real test runs this session — `flutter test` (25/25 relevant voice/locale tests passed: `mobile/test/core/flutter_tts_voice_service_test.dart`, `voice_language_controller_test.dart`, `location_language_resolver_test.dart`, `voice_service_test.dart`, `mobile/test/language_switch_live_test.dart`) and backend `pytest tests/test_assistant_chat.py -k daily_summary` (4/4 passed, including the two `language_code` override tests). Headline result: Voice/Local-Language (40–41) is substantially real and well-tested — TTS output, a manual/GPS-detected audio-language mode, and full 651/651-key parity across all 7 `.arb` files are all genuine and verified — but voice **input** (speech-to-text) does not exist anywhere in the codebase, and non-Daily-Briefing backend advisory text is deliberately English-only pending native-speaker review. Education (42), Community (43), Machinery (45), and Labour (46) are confirmed almost entirely MISSING by direct grep (no models, services, endpoints, or Flutter screens), consistent with this project's own repeatedly-disclosed farmer + AI-assistant + professional-network(experts) + dealer-marketplace scope, never a general classifieds/community/rental platform. Nearby Services (44) covers only 2 of 13 listed service types (Expert fully, Dealer partially via a non-geo marketplace) with the other 11 either entirely absent or existing only as unseeded role-vocabulary stubs (`Role.TRANSPORTER`, `Role.LAB`).
