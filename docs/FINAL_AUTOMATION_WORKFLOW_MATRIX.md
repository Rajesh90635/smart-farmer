# Final Automation Workflow Matrix

Every workflow below is either scheduler-driven (runs without any farmer request) or
rule-triggered as a side-effect of an existing request (fires automatically once the
triggering condition is met, without a separate farmer action to invoke it). Pure CRUD
(create/edit/list a Farm/Plot/Crop/Task) is excluded — it is manual by definition and
already covered in the scenario matrix. Citations are to the same code already cited in
`docs/audit/c0*.md`; this table adds the Trigger→...→Follow-up breakdown the scenario
matrix format doesn't have room for.

## Automation coverage

The original audit's README explicitly declined to publish a coverage percentage,
disclosing that inconsistent column layouts across the 13 sub-agent files made positional
extraction of Trigger/Automatic-Action columns unreliable, and chose not to publish a
fabricated number rather than guess. This document is built directly from the same
per-scenario evidence, hand-verified per workflow above (13 genuine automatic/triggered
workflows identified, all now VERIFIED), rather than a mechanical re-parse — so it does
not repeat that specific failure mode, but a single scalar "automation coverage %" figure
would still require deciding a denominator (which of the 798 scenarios are "applicable
automation candidates" at all, as opposed to inherently manual/farmer-initiated actions
like registering a farm or filing a dispute). That denominator decision was not made by
this pass and is not fabricated here — of the workflows that exist and are automation
candidates, all 13 are VERIFIED (real trigger, real rule, real action, real audit trail).
